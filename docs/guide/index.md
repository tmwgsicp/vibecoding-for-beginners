# 教程介绍

## 这是什么?

这不是传统的编程教程。

这是一套 **用AI做产品的实战方法论**:
- 如何思考和发现问题
- 如何与AI高效协作
- 真实项目的开发过程
- 常见的坑和解决方案

**重点:** 不是教你"怎么写代码"，而是"怎么用AI做产品"。

## 给谁看的?

想用AI做产品的人，尤其是:
- ✅ 完全不会编程，但想用AI做点东西
- ✅ 会一点编程，想提高AI协作效率
- ✅ 想做自己的产品，不知道怎么开始
- ✅ 想了解"非技术背景"怎么做产品

**不需要编程基础。**

## 你会学到什么?

不是"Python语法"、"JavaScript框架"这些（AI会）。

而是:
- 怎么找到值得做的项目idea
- 怎么和AI讨论方案（而不是直接让AI写）
- 怎么拆解任务、逐步实现
- 怎么测试和调试
- 怎么做架构设计
- 怎么部署上线（域名、DNS、证书这些概念，再用 vibe-launch 一句话部署）
- 怎么从开源到商业化
- 怎么避开我踩过的坑

## 常见问题

### Q: 完全不会编程，真的能学吗?
A: 能。重点是学方法论和思维方式，AI会帮你写代码。你只需要知道"要做什么"，不需要记语法。

### Q: 需要多长时间?
A: 方法论 14 章大概 3-5 天快速浏览,1-2 周深入理解。后续边做边学。

### Q: 学完能做什么?
A: 能开始做自己的项目。做的过程中遇到问题，回来查对应章节。

### Q: AI工具需要付费吗?
A: 认真做项目建议付费。能访问海外的，Claude Code 或 Codex 选一个就够；不方便访问海外的，用通义灵码/Trae 配国内模型。各家价格变化快，以官网为准，详见 [AI 工具选择指南](/guide/05-tools/ai-tools-guide)。
