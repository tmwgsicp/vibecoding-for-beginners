---

## 现在的 AI 编程工具是什么样的?

以前 AI 编程工具主要是"在编辑器里帮你补代码"。现在主流的是**能自己读文件、改代码、跑命令的 AI 助手**:你说要做什么,它自己去看项目、动手改、跑测试,再告诉你结果。

Claude Code、Codex 都是这一类。它们最早在终端里用,现在也都有桌面 App 和编辑器插件,不想用终端也可以。

## 能访问国外

### Claude Code - Anthropic 出品

**官网:** https://code.claude.com/

**安装:**
```bash
# macOS/Linux/WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell
# Windows PowerShell
irm https://claude.ai/install.ps1 | iex
```

装好后在项目文件夹里输入 `claude`,第一次会让你登录。

**怎么付费:**
- 免费版不能用 Claude Code
- Pro: $20/月,入门够用
- Max: $100/月起,天天重度用、经常撞到额度上限再考虑

**模型:**
- Opus 5.5: 官方建议多数场景先用它
- Fable 5.1: 目前最强,适合特别难的推理和架构问题
- Sonnet 5.5: 便宜一些,日常开发够用

---

### Codex - OpenAI 出品

**官网:** https://github.com/openai/codex

**安装:**
```bash
npm install -g @openai/codex
```

装好后在项目文件夹里输入 `codex`,用 ChatGPT 账号登录。也有桌面 App 和 VS Code 插件。

**怎么付费:**
- ChatGPT Plus: $20/月,包含 Codex
- Pro: $100/月起,额度更多

---

### 怎么选?

两个能力都够用,区别主要在习惯:界面、回答风格、你本来订阅的是哪家。

**我的建议:**
- 选一个当主力,用熟了再说
- 直接选能力最强的,不纠结
- 真遇到额度用完或网络问题,再换另一个
- 时间比钱贵

## 无法访问国外

两条路选一条:

- **不想碰终端:** 用 [Trae](https://www.trae.cn)(字节跳动),装好就有界面
- **想用 Claude Code:** 买 Kimi 或智谱 GLM 的编程套餐接进去,用法和上面一样。官方都有接入文档,看不懂就把链接发给 AI 让它带你配

这不是省钱方案,认真做项目一样要付费,价格以官网为准。

## ❓ 常见问题

### 新手应该选哪个?

**能上国外:** Claude Code 或 Codex,选一个

**网络受限:** Trae,或 Claude Code 接 Kimi / 智谱 GLM

学习阶段可以用免费额度,认真做项目就要付费。

---

### AI 工具值得花钱吗?

**我的经验:**

值得,非常值得。

$20/月提升效率 5-10 倍,做出第一个产品就能回本。

不要在工具上省钱,时间更贵。

---

### Claude Code 和 Codex 有什么区别?

做的事情差不多:都能读代码、改代码、跑命令、跑测试。

- Claude Code: 用 Claude 模型,还能接国内模型
- Codex: 用 OpenAI 的模型,用 ChatGPT 账号登录

选你用着顺手的那个。两个都用也行,我就是两个都用。

---

### 还要用 Cursor 吗?

Cursor 还能用,它是一个带 AI 的编辑器,也能选多种模型,价格以官网为准。

但现在 Claude Code、Codex 已经能独立完成大部分工作,新手不用为了它多付一份钱。已经在用 Cursor 的,也可以在 Cursor 里装 Codex 插件或在它的终端里跑 Claude Code。
